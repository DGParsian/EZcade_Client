# EZcade_Client

## خلاصه برنامه

EZcade_Client یک برنامه دسکتاپ تحت ویندوز است که به عنوان رابط کاربری بین سیستم سخت‌افزاری EZcade و سرور مرکزی عمل می‌کند. این برنامه برای مدیریت فرآیندهای تولید و ردیابی قطعات الکترونیکی طراحی شده است.

### قابلیت‌های اصلی برنامه

#### ۱. احراز هویت و مدیریت کاربر
- ورود امن به سیستم با استفاده از نام کاربری و رمز عبور
- ذخیره اطلاعات ورود برای ورود خودکار در اجراهای بعدی
- ارتباط با سرور از طریق API مبتنی بر توکن

#### ۲. انتخاب و مدیریت دسته‌ها (Batches)
- دریافت لیست دسته‌های قطعات موجود از سرور
- نمایش اطلاعات دسته‌ها شامل نام، تعداد و وضعیت
- امکان انتخاب دسته مورد نظر برای فرآیند تولید

#### ۳. تولید و مدیریت شماره سریال
- دریافت شماره سریال‌های یکتا از سرور برای هر قطعه
- نمایش شماره سریال‌های صادر شده به صورت واقع‌زمان
- امکان ویرایش و لغو شماره سریال در صورت نیاز

#### ۴. ارتباط با سخت‌افزار EZcade
- اتصال به سیستم محلی EZcade از طریق TCP (پورت 1000)
- دریافت درخواست‌های چاپ از سخت‌افزار
- ارسال دستورات چاپ کد دیتاماتریکس به دستگاه

#### ۵. حالت‌های پردازش
- **حالت دستی**: پردازش تک به تک درخواست‌ها با تأیید اپراتور
- **حالت خودکار**: پردازش گروهی درخواست‌ها به صورت خودکار
- امکان تعویض بین حالت‌های مختلف بر اساس نیاز تولید

#### ۶. چاپ کدهای دیتاماتریکس
- دریافت اطلاعات قطعه (شماره سریال، کد DM) از سرور
- ارسال دستورات چاپ به پرینتر دیتاماتریکس
- تأیید موفقیت‌آمیز بودن عملیات چاپ

#### ۷. فعال‌سازی محصولات
- ارسال درخواست فعال‌سازی برای قطعات تولید شده
- ثبت نهایی اطلاعات قطعه در سیستم مرکزی
- به‌روزرسانی وضعیت دسته‌ها پس از تکمیل فرآیند

### معماری فنی

- **پلتفرم**: C# .NET 8 با رابط کاربری WPF
- **ارتباط سرور**: HttpClient برای ارتباط REST API
- **ارتباط سخت‌افزار**: TCP Socket برای اتصال به EZcade
- **ذخیره‌سازی**: Settings برای نگهداری اطلاعات کاربر

### جریان کاری کلی

1. **ورود به سیستم**: اپراتور با نام کاربری و رمز عبور وارد می‌شود
2. **انتخاب دسته**: دسته تولیدی مورد نظر از لیست انتخاب می‌شود
3. **دریافت شماره سریال**: شماره سریال‌های مورد نیاز از سرور دریافت می‌شوند
4. **پردازش درخواست‌ها**: درخواست‌های چاپ از سخت‌افزار دریافت و پردازش می‌شوند
5. **چاپ کد**: کدهای دیتاماتریکس بر روی قطعات چاپ می‌شوند
6. **فعال‌سازی نهایی**: اطلاعات قطعات در سیستم مرکزی ثبت نهایی می‌شوند

### مزایای برنامه

- **اتوماسیون کامل**: کاهش خطاهای انسانی در فرآیند تولید
- **ردیابی دقیق**: ثبت کامل اطلاعات هر قطعه تولیدی
- **ارتباط یکپارچه**: اتصال همزمان به سرور مرکزی و سخت‌افزار محلی
- **رابط کاربری ساده**: طراحی کاربرپسند برای اپراتورهای تولید
- **مدیریت متمرکز**: کنترل کامل فرآیندها از طریق سرور مرکزی

این برنامه بخش کلیدی از خط تولید است که اطمینان حاصل می‌کند هر قطعه تولیدی دارای شناسه منحصر به فرد بوده و به درستی در سیستم مرکزی ثبت می‌شود.
